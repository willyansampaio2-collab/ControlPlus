# Control+

Aplicativo mobile desenvolvido em React Native com Expo e Firebase para monitoramento e controle de hábitos e vícios.

## Tecnologias

- React Native
- Expo
- TypeScript
- Firebase Authentication
- Firebase Firestore
- Expo Router

## Estrutura do Projeto

src/

- components
- context
- hooks
- navigation
- screens
- services
- styles
- types
- utils

## Integrantes

- Integrante 1 — Integração e Arquitetura
- Integrante 2 — Login e Cadastro
- Integrante 3 — Firebase
- Willyan Sampaio — Dashboard/Home
- Integrante 5 — Histórico
- Integrante 6 — Perfil e Estatísticas
- Integrante 7 — Testes e Documentação

## Como executar

npm install

npm start

## Objetivo

Auxiliar usuários no acompanhamento de hábitos e vícios através de métricas, histórico, estatísticas e metas personalizadas.
