# API Control+ — trabalho acadêmico

Back-end em **Java 17, Spring Boot 3, Maven, JPA e PostgreSQL**.

## Para iniciar

1. Instale o JDK 17 ou superior e Maven.
2. Instale PostgreSQL e crie um banco chamado `controlplus`.
3. Configure as variáveis `DB_USER`, `DB_PASSWORD` e, se necessário, `DB_URL`. Os valores padrão estão em `src/main/resources/application.properties`.
4. No terminal, entre na pasta `backend` e execute `mvn spring-boot:run`.
5. A API estará em `http://localhost:8080`.

Este projeto foi feito para estudar Controller, Service, Repository, Entity, DTO, HTTP e persistência. Não possui autenticação nem segurança de produção; não publique dados pessoais reais.
